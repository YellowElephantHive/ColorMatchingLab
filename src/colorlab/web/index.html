資料處理與評估規模

依 DY 與 MN 製程階段，選取對應量測建立模型比較。

WHAT CHANGED

從製程資料到模型應用

  • 明確定義標記整理 PASS / NO-PASS 標記，處理缺值、重複與衝突紀錄。
  • 隔離相關樣本同一基礎工單（含 A/B 後綴）與完全相同 Lab 輸入留在同一折。
  • 統一特徵計算DE 重算 CMC(2:1)；ΔL、Δa、Δb 為量測減 IN 標準。撥水 DE 以 DY 標準為參考。
  • MN 使用實測值依製程階段選取 DY 或 MN 量測，將實測來源與補值來源分開管理。
  • 成果可追溯每次執行產生模型檔、逐筆預測、資料分割與來源雜湊，方便比較與重跑。

專案亮點

製程知識與特徵設計

結合染整流程、Lab 量測與 CMC 色差，將現場對色判定轉化為可建模的資料問題，涵蓋 QD 與撥水加工情境。

企業應用

專案完整模型已於公司部署。本作品透過製程分析、模型比較與即時試算，呈現從實驗開發到企業應用的技術經驗。

工程化與互動展示

整合可重跑的訓練流程、Python 推論介面、模型一致性測試與中英文互動視覺化，讓模型成果可以直接操作與說明。
